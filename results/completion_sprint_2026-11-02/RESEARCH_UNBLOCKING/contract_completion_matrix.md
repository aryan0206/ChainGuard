## Shared execution and analysis contract

An independent security unit is a workflow **parent**. Calls, prefixes, metamorphic variants, mutants and timing repetitions are nested observations. Freeze parent identity, split, case IDs, source/policy/configuration digests, raw proposal/control stream, expected authorization and effect fields, capture coverage and exclusions before execution. Record source result, ordered control and reservation COMMIT, forward attempt, handler arrival/non-arrival with capture coverage, exact sink bytes/digest, task output and audit closure as distinct axes. Missing witness means `UNKNOWN`/`NOT_CHECKED`, never a negative observation. Record every failure. Separate development, validation and held-out parents. For binary proportions, show numerator, eligible denominator and unknown/excluded counts; compute a Wilson interval only when a meaningful independent-parent denominator exists. For paired systems, calculate within-parent differences and use paired uncertainty only with enough independent parents. Never treat a prefix or repetition as an independent security sample. For benchmark repetitions, show median/IQR; p95 only when the frozen repetition count supports it. A claim of completion requires all required case classes below, not merely one passing check.
